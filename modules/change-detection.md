# Change Detection Module

Tracks competitive movements over time to detect shifts in trajectory rather than isolated events.

## Change Matrix
- **Pricing Shift**: Packaging updates, base fees, free limits.
- **Product Expansion**: Release cycles, API updates, documentation growth.
- **Organization shifts**: Hiring profiles (e.g., enterprise sales hires), job posting patterns.

## Correlation Loop
Combine multiple distinct changes to formulate high-confidence strategic inferences.
- **Example**: Enterprise pricing page + Security landing page + Enterprise sales hiring.
- **Output**: Strategic inference of "Enterprise push" with high confidence.
