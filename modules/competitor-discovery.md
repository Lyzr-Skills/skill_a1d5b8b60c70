# Competitor Discovery Module

Identifies and classifies companies in the competitive arena.

## Scope Inputs
- **Company**: Target under analysis.
- **Industry / Market**: Sector classification.
- **Product**: Core value driver.
- **Geography**: Regional focus.
- **Target Customer**: Audience segment.

## Competitor Categories
1. **Direct**: Same customer, same problem.
2. **Indirect**: Same customer, different solution.
3. **Emerging**: New entrants showing early signals.
4. **Substitute**: Alternatives to solving the problem without dedicated competitor tools.
5. **Potential**: Highly adjacent companies that could expand.
