# Customer Sentiment Module

Aggregates and interprets customer reception and reviews across public platforms.

## Raw Sources
- Software review sites (G2, Capterra, TrustRadius).
- Forums and developer communities (Reddit, Stack Overflow, Discord).
- App stores and social platforms.

## Core Rules
Sentiment is a *Signal*, not absolute truth. Reports must structure sentiment objectively:
- **Observed Sentiment**: Positive, Negative, Neutral.
- **Top Mentions/Complaints**: Specific topics.
- **Evidence Count**: N conversations/reviews.
- **Confidence Rating**: Based on volume and source independence.
