# Competitive Intelligence Skill

Structured pipeline transforming competitor raw data into validated market intelligence.

## Pipeline Overview

1. Define competitive landscape
2. Gather signals & changes
3. Formulate inferences
4. Detect opportunities and threats
5. Prioritize via mathematical scoring models

## Folder Hierarchy

- `core/`: Decision policies and processing contracts.
- `config/`: Global targets and weights.
- `evidence/`: Verification and contradiction rules.
- `modules/`: Feature-specific metrics.
- `prompts/`: LLM prompt instructions.
- `schemas/`: Strict JSON contracts.
